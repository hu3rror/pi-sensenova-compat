# pi 0.99.1 → 1.0.2 重验：内部 seam 未变，扩展无需改动

决定：把本扩展的声明基线从 pi **0.99.1** 跟进到 **1.0.2**（2026-10-04 的 npm `latest`，与宿主机 mise 安装版本一致）。逐 seam 重验后确认 0.99.1→1.0.2 无影响本扩展的行为变更，**不改代码、不加依赖**。ADR 0001–0003 中的 0.99.1 记录保持历史原样，本 ADR 是当前验证基线。

## seam 清单与重验结论

本扩展**不 import 任何宿主包**、不 patch prototype（ADR 0002 的零运行时依赖），因此不存在 `dist/` 深导入失效或 prototype 方法变 class field 的风险。实际要盯的 seam 只有三类：注册 API 面、镜像的 mime 嗅探规则、models.json schema。

| seam | 位置 | 0.99.1→1.0.2 | 证据 |
| --- | --- | --- | --- |
| mime 嗅探镜像（`detectImageMime`） | `dist/utils/mime.js` | **文件逐字节相同** | `diff -u` 无差异；524 例差分模糊（acTL 动图 PNG、JPEG `0xf7`、GIF87a/89a、RIFF/WEBP、BMP 各 DIB 头/平面数/位深/偏移边界、随机字节）对拍 pi `detectSupportedImageMimeTypeFromFile`，0 mismatch |

## 运行时冒烟（对 1.0.2 实机）

用 1.0.2 的 SDK `createAgentSessionServices({ additionalExtensionPaths })` 装载扩展（等价 `pi -ne -e ./`）：

- extension diagnostics 为空；
- provider `sensenova-images` 注册，`getModelsOfType("image", "sensenova-images")` 返回 2 个 `type:"image"` 模型（api/provider/baseUrl 正确）；
- 工具 `sensenova_generate_image` 出现在 active tools；
- 命令 `sensenova-image` 注册。

注意 `--list-models` 只列 chat 模型，image 模型不出现属预期（1.0.2 的 chat 面向读取仍排除 image），不能用它判断 provider 是否注册成功。

## 审阅过但不影响本扩展的上游变更

- **1.0.0 codemode `models.generateImages()` / `ctx.modelRegistry.generateImages()`**：加法，新增调用入口；本扩展既是 provider 实现、也直接调用自身 `generateImages`，注册 seam 不变。
- **1.0.1 `pi.registerToolRenderer()`**：加法，可选渲染器。
- **1.0.2 `samplingParamsByThinkingLevel`**：加法；本扩展模型不声明 `samplingParams`，无影响。
- **1.0.2 移除 `npm-shrinkwrap.json`、直接 pin `brace-expansion@5.0.12`**：npm 侧依赖策略；本仓库零依赖、无 lockfile（ADR 0002），无 `audit`/`overrides` 事项。
- **1.0.2 修复扩展经 `Image` 渲染 JPEG/GIF/WebP**：TUI 渲染修复；本扩展工具返回本地文件路径而非图像块，不受影响。

## 未覆盖 / 需人工验证

- 真实 SenseNova 端到端（`/login` 后 `sensenova_generate_image` 与 `/sensenova-image gen|edit` 实跑）依赖凭据与网络，本次重验未执行。[NEEDS MANUAL VERIFICATION]

## 下次重验的可复现步骤

1. `npm pack @earendil-works/pi-coding-agent@<old>`，与宿主 `dist/` 逐文件 `diff`（重点 `utils/mime.js`、`core/provider-composer.js`、`core/model-config.d.ts`、`core/extensions/types.d.ts`、`core/model-registry.d.ts`）。
2. `npm pack @earendil-works/pi-ai@<version>`，对 `types.d.ts` 做同样 `diff`。
3. 跑 mime 对拍（边界样本 + 随机字节，对拍 pi `detectSupportedImageMimeTypeFromFile`）。
4. 用 `createAgentSessionServices({ additionalExtensionPaths: [...] })` 装载扩展，断言 diagnostics 为空、image 模型/工具/命令均注册。
